# API surface for integrators

- Base `https://api.vitrinadev.com/api/v1`; MCP `https://api.vitrinadev.com/mcp` (Streamable HTTP, `Authorization: Bearer sk_…`); `/api/v1/mcp` is 404.
- Generic MCP tools (`src/mcp/tools/public-api.ts`): `search_operations {query?, tag?, limit 1–100}` → `{total, returned, tags[], operations[{operation_id, method, path, tag, tier, destructive, writes, summary, scopes}]}`; `describe_operation {operation_id}` → `{operation_id, aliases, method, path, url, tag, tier, destructive, summary, description, scopes, parameters, request_body?, responses?}`; `call_operation {operation_id, params?, body?, idempotency_key?}` — params flat (path + query), undeclared params refused, GET with body refused, body must be a JSON object, multipart impossible, binary responses return metadata only, errors thrown as `"<METHOD> <path> answered <status>: <envelope>"`, default idempotency key `mcp-<sha256(op, params, body)[:32]>` on every non-GET.
- Tiers: `estable` (none yet), `beta` (everything published), `interna` (reason required; REST-reachable with the scope, invisible to `call_operation`). Sensitive tags (Clinic Patients, Record, Consents, Documents) are never in the MCP catalogue.
- Rate limit (`src/middlewares/rate-limit.ts`): 120/min per key (tenant override `rate_limit_per_minute`), personal tokens share the member's bucket, UI sessions 600/min, public IP 300/min; headers `X-RateLimit-Limit/-Remaining`; 429 `RATE_LIMITED` + `Retry-After`; fails open without Redis; `/mcp` hand-written tools are not limited, each `call_operation` spends one token.
- Idempotency: `Idempotency-Key` `[A-Za-z0-9_-]{8,200}`, 24 h, per tenant + credential, only 2xx cached, `X-Idempotent-Replay: 1`, 409 `IDEMPOTENCY_KEY_CONFLICT`; automatic only on POSTs to estable/beta operations (PUT/PATCH/DELETE and interna POSTs are not covered unless the route opts in).
- Errors: `{error:{code, message, requestId, details?, field_errors?}}`; cross-tenant record = 404.
- Pagination: cursor (`limit` 1–100 default 20, `cursor`, `meta.pagination.nextCursor`), offset (`limit`/`offset`, `meta.total`), page (`page`/`limit` ≤200). Envelope `{data, meta}`.
- Display ids (`src/utils/display-id.ts`): T ticket, C conversation, L lead, A appointment, B location, D solicitud, Q quote, R reservation, V sale note, P purchase note, S settlement, F credit, E clinic budget — paths only.
- API keys: `api_keys_list` (api_keys:read), `api_keys_create {name, scopes, expires_at?, livemode?}` (api_keys:write; scopes ⊆ caller's; unknown scope → 400; restricted-visibility members cannot mint), `api_key_rotate_create {grace_period_hours 0–72 (24)}`, `api_key_delete` (destructive). `sk_test_` keys need a provisioned sandbox (`POST /sandbox/clinic|automotive`).
- Publishable keys (ADR 0033): REST `/publishable-keys` (api_keys:write, interna); fixed scopes `stock:read, leads:intake, widget:chat, appointments:intake, storefront_events:write`; origin allowlist; per-IP limits; routes `/widget/stock`, `/widget/website-leads`, `/widget/appointments/availability`, `/widget/appointments`, `/widget/appointments/:token`, `/widget/clinic/availability(/days)`, `/widget/clinic/bookings`, `/widget/clinic/drafts`, `/widget/clinic/appointments/:token`, `/widget/storefront/events`.
- Webhooks: MCP `webhooks_list`, `webhooks_create {url, events[1..20], description?}` (notice-only), `webhooks_delete {id}` (webhooks:read/write); REST adds `include_data`, `webhook_replace`, `webhook_resume_create`, `webhook_deliveries_list`, `webhook_delivery_redeliver_create {deliveryId: integer}`; catalogue `webhooks_events_list` (large, with samples). Headers `X-Webhook-Event`, `X-Webhook-Event-Id`, `X-Webhook-Timestamp`, `X-Webhook-Signature: t=<unix>,v1=<hex>` (HMAC-SHA256 over `${t}.${rawBody}`, secret `whsec_…` shown once), `Vitrina-Livemode`; replay window 300 s; retries 5× 5/10/20/40/80 s; auto-pause after 20 consecutive exhausted events or 24 h; `data_omitted: owner_unavailable` when the owning key was revoked. Events include `contact.created|updated|merged`, `conversation.*`, `lead.*`, `appointment.booked|rescheduled|cancelled|completed|no_show|reminded|imported`, `campaign.sent|paused`, `ai_agent.publish`.
- Specs and SDK: `openapi.public.json` at `GET /api/v1/docs/openapi.json` (767 operations at v12.3); internal `openapi.json`; TS types `clients/typescript/api-types.ts`; SDK `@vitrina/api` (`packages/api-sdk`, openapi-fetch, `createClient({baseUrl, apiKey})`).
- Docs (`docs.vitrinadev.com`, es + en): `empezar`, `autenticacion`, `errores`, `versiones`, `sdk`, `sandbox`, `tokens-personales`, `webhooks`, `datos-personales`, domain chapters (`contactos`, `conversaciones-y-tickets`, `enviar-mensajes`, `leads-y-embudos`, `agenda-y-citas`, `whatsapp-plantillas-y-flows`, `agentes-ia`, `base-de-conocimiento`, `analytics`, …), `mcp/{index, claude, claude-code, cursor, operaciones, anuncios, problemas}`, `clinicas/*`, `automotoras/*`, `recetas/*` (12 how-tos).
