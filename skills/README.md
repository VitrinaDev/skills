# Skills

One folder per skill. All are **model-invoked** (the agent reaches for them from the description; you can also type `/name`).

- **[improve-vitrina-agent](./improve-vitrina-agent/SKILL.md)** — Diagnose and fix a Vitrina AI agent: read its config, inspect the conversations where it misbehaved (messages, tool calls, reasoning, the assembled prompt), find the layer at fault, edit through MCP/REST, verify.
- **[analyze-business](./analyze-business/SKILL.md)** — Research a business from its conversation corpus or its interviews and draft the agent package (instructions + skills + KB + setup, billing estimate). Corpus export needs direct database access (Vitrina staff).
